What education
data looks like

The Common Education Data Standards Ontology is a single machine-readable description of American education — every entity a system might record about a learner, a teacher, a school, or a building, and the named relationships between them. This page reads the ontology file directly and draws what is inside it.

The one idea

A person, an organization,
and the role that joins them

Almost every fact in education data is really a fact about a relationship. CEDS names that relationship Membership — a role a person holds at an organization over a defined period of time — and then specializes it. Enrollment, employment, assignment and program participation are not separate ideas in this model. They are all the same idea, narrowed.

Why this matters. Once enrolling, teaching, and participating are the same shape, a question like “who was connected to this school last spring, in any capacity?” has one answer path instead of six. It is also where governance attaches: a membership is the thing you grant access against, and the thing that ends.

The vocabularies

965 controlled code sets

Beyond entities and relationships, the ontology carries the permitted values — every race category, disability type, diploma type, and course code, each one an identified concept rather than a loose string. This is the part that makes two districts’ data comparable.
